## What's New

v0.21.0 authenticates ESP-NOW play and closes the reviewed clock, material,
search, and puzzle-progress holes from v0.20.0.

> **Multiplayer compatibility:** both devices must run v0.21.0 or another
> protocol-v7 build. v0.20.0 and every earlier multiplayer protocol are
> rejected. Upgrade or roll back both Cardputers together.

### Clocks

- Save a running local or AI clock at least every five seconds, using the
  existing saved game. A power loss no longer refunds the time spent thinking
  since the last move.
- Keep online games unsaved. Each device remains the authority for its own
  clock.
- Ignore a heartbeat that raises the opponent's clock by more than 200 ms.
  Reject a move that raises it by more than one increment plus that skew, and
  a time-gift acknowledgement that raises it by more than 15 seconds plus that
  skew. Those two cases disconnect with "Clock out of sync".
- Cap a timed AI search by the side-to-move remaining time so a bullet game
  does not think for the full difficulty budget.

### Chess, Search & Puzzles

- Treat two knights versus a lone king, or a king plus queens only, as a draw.
  Three or more knights can still mate, a knight plus a bishop can still mate,
  and two knights can still mate when the opponent has a non-queen blocker.
- Keep search move lists in static memory instead of on the 32 KB loop stack.
  Discard an aborted search iteration, including depth 1, instead of treating
  its zero score as a draw.
- Open Mate in 1, Mate in 2, and Tactic at the first unsolved puzzle of that
  type. Next still opens the first unsolved puzzle of any type.

### Multiplayer

- Carry an X25519 public key in discovery and accept packets. Both devices
  show the same 6-digit pair code, and the game starts only after both players
  press Match. Cancel tears the pairing down. The shared secret is never sent.
- Authenticate GameStart, GameStartAck, Move, MoveAck, Heartbeat, Control, and
  ControlAck with a truncated HMAC. Drop a session packet whose tag does not
  match.
- Ignore legacy one-way resign packets. A resignation is an authenticated
  GameEnd bound to the current position, and it must award the win to the
  receiver. It is accepted on either turn so an explicit quit still reaches
  the opponent.
- Record a loss and send that resignation when a player quits an unfinished
  online game. A dropped link still shows Wait and does not by itself award a
  result.

### Saved Data

- App-only upgrades at `0x10000` preserve NVS profiles, saves, results, puzzle
  progress, and settings when the existing partition layout is compatible.
- The save format is unchanged from v0.20.0. Existing Local and AI saves
  remain readable.
- A clean factory installation that erases flash removes saved games, profiles,
  results, puzzle progress, and settings. Online sessions remain non-resumable.

### Deferred Larger Enhancements

Full multiplayer premoves, complete-game replay archives, and a dedicated win
celebration remain deferred to later releases.

## Binaries

These binaries target the **M5Stack Cardputer Advance with 8 MB flash**.

| File | Flash offset | Description |
|------|-------------|-------------|
| `cardputer-chess-0.21.0-m5-burner.bin` | `0x0000` | Complete factory image for M5Burner/manual installation, including bootloader (`0x0000`), partitions (`0x8000`), OTA selector (`0xE000`), and app (`0x10000`) |
| `cardputer-chess-0.21.0-app.bin` | `0x10000` | App-only image for a compatible in-place upgrade that preserves data partitions |
| `firmware.bin` | `0x10000` | Byte-identical compatibility alias of the versioned app image |
| `cardputer-chess-0.21.0-cardputer-advance-flash-bundle.zip` | Multiple | Manual/recovery bundle with individual components, exact offsets, and flashing instructions |
| `cardputer-chess-0.21.0-debug.zip` | Not flashable | ELF and map files for crash diagnosis |
| `release-manifest.json` | Not flashable | Version, source commit, target, protocol, flash layout, sizes, tool versions, and artifact hashes |
| `SHA256SUMS` | Not flashable | SHA-256 checksums for release-artifact verification |

Use the complete image only at `0x0000`. Use the app image or `firmware.bin`
only at `0x10000`. A clean factory erase is destructive; an app-only update does
not erase compatible NVS or data partitions.

## Validation

The published release records its exact source commit, CI run, image sizes, and
checksums. `release-manifest.json` identifies the source commit, compiler and
PlatformIO versions, protocol, flash components, and hashes for the attached
artifacts. `SHA256SUMS` verifies the complete download set.

Automated coverage includes the native test suite and the engine/scene
regressions under AddressSanitizer and UndefinedBehaviorSanitizer. Those
regressions cover the new draw material, aborted search scores, running-clock
resume, puzzle categories, bad packet tags, resignation, clock bounds, online
quit, and pair-code confirmation. The release workflow also checks the
production build, partition limits, image layout, manifest, checksums, and
ESP32-S3 image integrity.

Physical-device validation remains **unverified**: factory installation, app-only
upgrade and power-cycle data retention, two-device ESP-NOW play, the pairing
screen on the 240x135 panel, the real loop-stack watermark, older-protocol
rejection on hardware, and installation through the M5Burner catalog. These
checks have not been represented as passed.

The GitHub release provides the M5Burner-compatible factory binary. The separate
M5Burner catalog entry has not been updated or validated as part of this release.
